# Akash Jena — SOC Analyst Portfolio

A responsive, dark green SOC/Blue Team portfolio website built with HTML, CSS and JavaScript.

## Folder structure

```text
Portfolio/
├── index.html
├── style.css
├── script.js
├── README.md
├── Akash_Jena_Resume.pdf
├── soc-hero.jpg
└── soc-about.jpg
```

## Run locally

1. Keep all seven files in the same `Portfolio` folder.
2. Open the folder in Visual Studio Code.
3. Open `index.html` in a browser, or use the VS Code Live Server extension.
4. Confirm that the resume and image files load correctly.

## Before publishing

- Review all personal details and links.
- Make sure the resume PDF is the latest version.
- Keep project claims limited to work you have completed and can explain.
- The portfolio currently lists one completed project and two completed certificates.
- The TryHackMe count is shown as previously reported; update it if your verified count changes.
- Contact information is public when this site is published. Remove any detail you do not want publicly visible.
